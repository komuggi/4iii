4iii台本を縦書きの PDF に


      
    


    

      

      
    
    
    

    
    
      
    
        行の頭の記号
        
    
          
          
          
          
          
    、で区切って打ちます。どれにも当たらない行がセリフで、文字数はセリフだけを数えます。SE とコメント・演技指示は「ト書きあり」にだけ出ます。行の頭の # と ## は見出し（トラック）です。
    
          
    
          
    
            
            
          
    
        
    
      
    
      
    
        ルビの書き方
        
    
          
          
          
          
          
        
    
        
    例：|漢字《かんじ》。始めの記号が無いときは、開きの前に続く漢字に付けます。ルビの字は文字数に入れません。
    
      
    
      
    
        設定（4iii.json と同じ形）
        
        
    
      
    
      
    
        塊（{名前} の中身）を読む
        
        
    parts/ の .txt を選びます（ファイル名が塊の名前）
    
      
    
    
    

    
    
      
    貼った台本はどこにも送らず、保存もしません（閉じると消えます）。「この設定で保存」は、記号などの設定だけをこの PC に 4iii.json で落とします。
    
      
    Export の PDF で印刷の画面が開くので、「PDF に保存」を選びます。用紙の向き・大きさは設定の export.pdf.size（書いていなければ、縦書きは A4 横・横書きは A4 縦）です。
